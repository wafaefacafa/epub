# 轻小说阅读器 (EPUB Light Novel Reader)

这是一个基于Streamlit开发的轻小说阅读器，提供可视化的网页操作界面。

## 功能特性

### 多维度检索
- **编号检索**: 支持通过书籍唯一编号快速定位资源
- **作者检索**: 按轻小说作者名称筛选作品
- **书名检索**: 直接搜索小说名称获取资源

### 下载功能
- **整本下载**: 将完整小说保存为单一EPUB文件
- **分卷下载**: 针对分卷发布的小说，支持按卷单独下载
- **图片下载**: 提取并保存小说中的插图或封面

### 格式转换
- 基于轻小说文库内容生成标准EPUB格式文件，适配电子书阅读器

## 安装步骤

### 前置要求
- Python 3.8 或更高版本
- pip 包管理器

### 安装依赖

```bash
cd EPUBReader
pip install -r requirements.txt
```

## 使用方法

### 启动应用

```bash
cd EPUBReader
streamlit run app.py
```

应用将在浏览器中自动打开（默认地址：http://localhost:8501）

### 使用流程

1. **搜索作品**
   - 在左侧选择搜索方式（编号/作者/书名）
   - 输入搜索关键词
   - 点击"搜索"按钮

2. **选择作品**
   - 从搜索结果中查看作品信息
   - 点击"选择"按钮选中目标作品

3. **下载EPUB**
   - 在左侧选择下载模式（整本/分卷/图片）
   - 如果选择分卷下载，使用滑块选择卷数范围
   - 点击"开始使用"按钮生成EPUB文件
   - 点击"下载EPUB文件"按钮保存到本地

## 技术架构

- **框架**: Streamlit - 提供可视化网页操作界面
- **网络请求**: Requests - 处理HTTP请求
- **HTML解析**: BeautifulSoup4 - 解析网页内容
- **EPUB生成**: ebooklib - 创建标准EPUB格式文件

## 注意事项

- 首次运行前请确保已安装所有依赖
- 下载的EPUB文件默认保存在 `output/` 目录
- 建议使用现代浏览器（Chrome, Firefox, Edge等）访问

## 故障排除

### 应用无法启动
- 检查Python版本是否 >= 3.8
- 确认已安装所有依赖：`pip install -r requirements.txt`
- 尝试清除缓存：`streamlit cache clear`

### 页面显示空白
- 检查终端是否有错误信息
- 确认端口8501未被其他程序占用
- 尝试指定其他端口：`streamlit run app.py --server.port 8502`
